# ONESHOT 结构

叙事版单人恶魔轮盘。一间办公室，三个人，一把玩具枪，一次装填。视角顺着三个人转一圈，已经发生的事留下来，还没射出的那一发交给下一个人。选择的差别来自三人之间的爱和恨，不来自另一套玩法。

笔记出处：[ONESHOT](https://app.notion.com/p/ONESHOT-3e2689d09be48054842dfea413417de2)

## 已经写下来的核心

- 三个可扮演的人：假警察、老板、嫌疑人。假警察是骗子，负责调查；老板负责旁观，办公室里有电话；嫌疑人负责开枪，能回溯，心里有明确的爱和恨。
- 玩具枪只装填一次：2 发空包弹，2 发实弹。射出之前不知道哪一发是哪一种。
- 情感句只有两种：「我爱你，所以把你杀了。」「我恨你，所以把你杀了。」
- 枪口里出来的，是子弹，也可能是别的东西。关系会在某一发之后翻转。
- 谜面可以先于过程出现：X 声枪响，Y 个人死了。笔记里的例子是三声枪响，一个人死了。

笔记里「同事」和「老板」交替出现，可杀对象又写成同事、假警察、自己。这里先把在场的人定成三个：假警察、老板、嫌疑人。嫌疑人嘴里的同事，就是老板。若同事是第四个人，下面的三角关系要重写。

## 回环到底在转什么

回环转的是视角，不是时间。

同一间房、同一把枪、同一次装填。上一轮结束时的尸体、电话、已经打出的子弹，原样放在下一轮开头。下一轮换一个人走进来，只能对还没被看见的部分做新的决定。

两样东西分开走：

| | 现场 | 关系 |
| --- | --- | --- |
| 内容 | 谁活着，谁在场，弹槽里还剩什么，哪一发已经打出、打在哪 | 嫌疑人与老板、与假警察、与自己；老板与假警察 |
| 方向 | 只往前。打出的子弹不装回去，死了的人不站起来 | 一轮最多翻转一条 |
| 作用 | 决定这一发还能不能改 | 决定这一发允许瞄准谁 |

玩家记得全部轮次。角色只知道自己看见的。知道下一发是实弹，不等于这个人愿意朝那个人开枪。知识拿掉不确定性，关系拿掉许可。两样都在，选择才不一样。

## 一轮

一轮是一个视角里的一段行动，然后交枪。

玩家每轮选择一个不同的视角。同一个人要等关系翻转之后才能再进。没有新关系、也没有剩余子弹的轮次不开场，避免同一段选择空转。

三个人能做的事：

- **老板**：恐吓，沉默，打电话。不打电话要等第一次电话结局出现之后才解锁。老板不开枪。
- **嫌疑人**：先声明一条爱或恨，再开枪。一轮最多三发。目标必须是这条关系允许的、并且在场的人，或者房间里的某处。
- **假警察**：检查证物，质询，把打出的弹壳标成空包弹或实弹。枪里还剩最后一发、而且嫌疑人还活着时，质询可以指定这一发指向嫌疑人自己或假警察。扣扳机的仍是嫌疑人。

第四发不在嫌疑人的三发额度里。它是交接发：房间里还有另一个能面对枪口的人时，才打得出去。否则它留在枪里，进入下一轮。

## 关系怎样改写选择

嫌疑人开枪前只持有一条情感。开局若先经历老板的蔑视，这条情感默认是恨老板。玩家可以保留它，也可以在这一轮把它翻成另一条。翻转只对之后的子弹生效，已经打进身体或已经被别人看见的那一发，只改句子，不改落点。

| 这一轮声明的关系 | 允许瞄准 |
| --- | --- |
| 恨老板 | 老板 |
| 爱老板 | 老板，或在场的假警察 |
| 恨假警察 | 在场的假警察 |
| 爱假警察 | 老板，或在场的假警察 |
| 恨自己 | 自己 |
| 爱自己 | 另外两个在场的人 |

人不在场就不能被瞄准。老板打了电话，假警察才会在嫌疑人的第二发之后进门，第三发和交接发才碰得到他。老板不打，假警察整段都不在，所有指向他的选项消失。

实弹打中人，人死。实弹打进房间，子弹落在那里，成为证物。空包弹只有枪声和弹壳。死法锁死后，句子仍可在后一个视角里从恨改成爱，或从爱改成恨。

## 弹槽

四发，洗好，开局全是未知。每人只在自己看见的时候知道结果：

- 嫌疑人在开枪的瞬间知道这一发是空是实。
- 老板若被打中，只知道打中自己的那一发是实弹。
- 假警察把弹壳捡起来，标成空包弹或实弹。这就是笔记里的弹槽计数。

已知装填是 2 空 2 实。三发都标完之后，最后一发可以用减法知道。没标完就不能算。笔记里「最后一颗是空包弹」是数完之后的结果，不是开场就告诉玩家的事实。

## 笔记里的那一晚，收成一条路径

这是一条打法，用来核对结构，不是唯一结局。

1. **老板。** 外面有威胁。他选择恐吓，然后打电话。电话举到一半，门外一发实弹打穿额头。这一发被看见：实弹、老板、死亡、死时手里是电话。动机还没人看见，不锁。假警察正在赶来。
2. **嫌疑人，回溯。** 老板的蔑视已经种下恨。他可以守着恨老板，也可以在某一发之后爱上对方。三发的额度里，有一发必须对上已经锁死的额头；另外两发还没人看见，可以打向自己、房间，或此时已经进门的假警察。笔记里的证词把这三发说成：第一发空包弹打向自己，第二发实弹打中老板，第三发没有解释。假警察看到的证物是另一套说法：老板中两枪，嫌疑人自己中一枪，一发在额头，一发在桌旁，一发在嫌疑人附近。第三发就是这个缺口，留给还没锁死的那一下。
3. **假警察。** 他数弹壳。若已经确认两实一空，枪里最后一发就是空包弹。质询之后，嫌疑人把这发指向自己或指向他。枪声响起，没有人死。若这一发留着不打，它就是下一轮唯一还能重新瞄准的子弹。

两条说法对不上的地方，就是下一轮的入口。假警察可以相信桌旁那一发仍是恨老板；也可以在质询里把句子翻转成爱。翻转之后，若枪里还有子弹，下一轮的目标菜单才变。

## 什么时候算走完

- 四发都有归属，每个死法都有一句双方视角不再打架的爱或恨。
- 枪里还剩子弹，房间里已经没有能扣动扳机的人。
- 关系翻转过，剩余子弹按新的菜单打完。

第一圈的顺序可以用笔记里的现场：老板，嫌疑人，假警察。玩家也可以从谜面进入，先当假警察。先当假警察时，额头上的实弹已经锁死，嫌疑人的回溯只能解释它，不能救回老板。先当嫌疑人时，老板还活着，这一发可以不朝他打，假警察后面走进来的就是另一个房间。顺序本身就是差分。

## 先保持开放的一句

「射出来的，是子弹，也有可能是……」

结构上，这一格留给关系翻转的那一发：弹壳仍然是空包弹或实弹，身体结果照旧，但这一发同时射出一句爱或恨。它是什么，笔记还没写完，不必在定结构之前定死。
